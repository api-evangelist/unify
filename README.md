# Unify

Unify is a B2B outbound and go-to-market platform that combines 25+ intent signals with AI agents and automated multi-channel sequences to help companies identify, qualify, and engage buyers automatically. Backed by the OpenAI Startup Fund, Thrive Capital, Battery Ventures, and Emergence Capital — https://www.unifygtm.com

This repository profiles Unify's developer surface for the API Evangelist network: three OpenAPI 3.1 specs (Data, Sequences, Analytics), official Python/TypeScript SDKs and intent clients, a hosted MCP server (mcp.unifygtm.com), seven provider-published agent skills, an llms.txt, and derived error, conventions, data-model, lifecycle, and security artifacts. See `apis.yml` for the index.
